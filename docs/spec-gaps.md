# 명세 보완이 필요한 미니게임

> design.md에서 **아직 구현하지 않은 미니게임** 중, 지금 명세만으로는 만들 수 없거나 해석이 갈리는 것만 모았어요.
> 각 줄의 "정해야 할 것"에 답을 주시면 바로 만들 수 있어요. 구현 현황 전체는 [game-audit.md](game-audit.md)에 있어요.

## 요약

아직 만들지 않은 **6종**은 모두 명세 보완이 필요해요. 설명만으로 만들 수 있는 게임은 모두 만들었어요. 답을 받아 만든 것은 맨 아래 [정해진 것](#정해진-것)에 모았어요.

| B. 설명은 있지만 풀이 방식을 알 수 없음 | 1 | 3 | 0 | 4 |

표에 `All_App_GameTitle_…` / `All_App_GameDesc_…` 같은 번역 키만 남아 있어요. 무엇을 하는 놀이인지부터 정해야 해요.
