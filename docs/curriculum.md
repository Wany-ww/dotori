# 한글 14단계 커리큘럼과 오늘의 할 일

하루에 한 차시씩 나아가요. 오늘의 할 일 6칸(도입 → 탐색 → 탐색 → 연습 → 연습 → 평가)은 차시 종류에 맞는 후보 놀이 중에서 날마다 하나씩 골라 채워요.
놀이들은 모두 그 차시의 글자·낱말·문장(js/lesson.js)으로 내용이 바뀌어요. 이 문서는 `js/curriculum.js`, `js/lesson.js`에서 자동으로 만든 거예요.

그림 낱말이 4개보다 적은 차시(예: 받침 ㄷ, 겹받침)는 그림이 꼭 필요한 놀이(선 긋기, 카드를 기억해, 낱말 카드, 장난감 공장, 낱말 퀴즈 은하, 낱말 완성하기, 열매를 받아라, 말소리 정류장, 설명해 주세요)를 빼요.
