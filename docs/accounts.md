# 보호자 계정 · 관리자 모드

도토리숲 서버(`npm start`, server.js)로 열면 **보호자 계정으로 로그인**해서 써요. 계정 하나에 아이 프로필을 여러 개 둘 수 있고, 아이별 학습 기록 · 산출물 · 접속 기록 · 이용 기록이 서버에 쌓여요. 관리자 계정은 모든 이용자의 정보를 읽기 전용으로 볼 수 있어요.

서버 없이 파일만 연 경우(claude.ai 체험판 등)에는 예전처럼 로그인 없이 이 기기의 브라우저에만 저장해요.

## 처음 할 일: 관리자 계정 만들기

```bash
npm run make-admin -- <아이디> <비밀번호> [이름]
```

- 아이디는 영어 소문자 · 숫자 · `_` 3~20자, 비밀번호는 8자 이상이에요.
- 이미 있는 아이디면 그 계정을 관리자로 바꾸고 비밀번호를 새로 정해요 (비밀번호를 잊었을 때도 이렇게 다시 정해요).
- 서버가 켜져 있어도 바로 반영돼요.

## 화면

| 주소 | 화면 |
|---|---|
| `#/account` | 보호자 로그인 |
| `#/signup` | 보호자 계정 만들기 (보호자 이름 · 아이디 · 비밀번호 · 기록 저장 동의) |
| `#/login` | 아이 고르기. 위에 계정 줄(보호자 이름 · 관리자 화면 · 로그아웃). 계정에 아이가 없고 이 기기에 계정 없이 쓰던 기록이 있으면 "이 계정으로 가져오기" |
| `#/admin` | 관리자: 전체 통계(보호자 계정 · 아이 · 오늘 접속 · 누적 놀이 · 산출물)와 이용자 목록, 검색 |
| `#/admin/u/<계정 id>` | 관리자: 이용자 한 명 — 계정 정보, 아이별 학습 현황, 이용 기록(아이 · 종류로 거르기), 접속 기록, 산출물 그림 |

## 저장하는 것 (`data/` 폴더)

| 파일 | 내용 |
|---|---|
| `data/users.json` | 계정: 아이디 · 보호자 이름 · 역할(parent/admin) · 가입일 · 마지막 로그인. 비밀번호는 scrypt 해시와 솔트만 |
| `data/sessions.json` | 로그인 세션 (쿠키 `sid`, HttpOnly, 30일) |
| `data/state/<id>.json` | 계정의 학습 상태: 아이 프로필, 한글 · 영어 차시, 수학 난이도, 오늘의 할 일, 별 · 도토리 · 스티커, 확인 퀴즈, 챌린지 지도 등 (학습 경과 누적) |
| `data/events/<id>.jsonl` | 기록 한 줄씩: 가입 · 로그인 · 로그인 실패 · 로그아웃 · 앱 열기(시각 · IP · 기기), 화면 이동, 아이 고르기 · 등록 · 삭제, 놀이 결과(놀이 · 차시 · 별 · 맞힌 수), 오늘의 할 일 완료, 확인 퀴즈, 챌린지 단계, 작품 저장, 차시 · 난이도 바꿈 |
| `data/works/<id>/` | 자유 활동 산출물: 그림(PNG)과 정보(JSON) |

- `data/` 폴더는 웹으로 내려받을 수 없게 막아 두었어요(403). 아이 개인정보가 들어 있으니 **백업은 이 폴더를 통째로 복사**하고, 공개 저장소나 공개 폴더에 올리지 마세요.
- 로그인을 10분에 10번 틀리면 그 IP는 10분 동안 로그인을 막아요.
- 관리자 화면은 읽기만 해요. 계정 삭제 · 비밀번호 초기화 같은 관리 기능은 아직 없어요(비밀번호는 위의 make-admin으로 다시 정할 수 있어요).

## API (server.js)

| 요청 | 하는 일 |
|---|---|
| `POST /api/signup` · `/api/login` · `/api/logout`, `GET /api/me` | 계정 · 세션 |
| `GET` · `PUT /api/state` | 계정의 학습 상태 받기 · 저장 (앱이 바뀔 때마다 1초쯤 모았다가 저장) |
| `POST /api/events` | 이용 기록 보내기 (3초쯤 모았다가, 창을 닫을 때 남은 것) |
| `GET` · `POST /api/works`, `GET /api/works/<id>(.png)`, `DELETE /api/works/<id>` | 산출물 |
| `GET /api/admin/users`, `/api/admin/users/<id>`, `/api/admin/works/<id>/<작품>.png` | 관리자 전용 |

## 학습 리포트

| 주소 | 누가 |
|---|---|
| `#/report` | 보호자 · 아이: 지금 고른 아이의 리포트 (위쪽 📊 단추, 프로필 화면의 "학습 리포트") |
| `#/admin/u/<계정 id>/r/<아이 id>` | 관리자: 이용자 정보 화면의 아이 카드에서 "📊 리포트" |

- **오늘의 학습**: 공부 시간 · 한 놀이 수 · 받은 별 · 한 번에 맞힌 비율, 한 줄 평(잘한 과목 · 더 연습할 놀이 · 마친 오늘의 할 일), 과목별 배운 차시와 오늘의 할 일 진행, 오늘 한 놀이 표(시각 · 과목 · 놀이 · 차시 · 별 · 맞힌 수 · 시간), 오늘 만든 작품
- **누적 학습**: 시작한 날 · 공부한 날 · 연속 학습 · 총 공부 시간 · 총 놀이 · 한 번에 맞힘 · 별 · 도토리 · 오늘의 할 일 완료 · 스티커 · 작품, 과목별 진도(한글 54차시 · 영어 96차시 · 수학 Lv), 과목별 놀이 수 · 시간 · 정답률, 최근 14일 과목별 공부 시간 차트(표로 보기), 많이 한 놀이, 한글 확인 퀴즈 기록, 영어 챌린지 지도 진행, 작품 모음
- "🖨️ 인쇄 · PDF"로 종이나 PDF로 저장할 수 있어요.
- 기록 방식: 놀이를 마칠 때마다 아이 프로필의 하루 기록(`log`, 최근 180일)에 과목 · 차시 · 별 · 맞힌 수 · 걸린 시간(한 판 최대 30분)을 남기고, 과목별 누적은 `stats.subj`에 쌓아요. 서버 모드에서는 계정 학습 상태와 함께 저장돼요. **공부 시간과 하루 기록은 이 기능을 넣은 뒤부터** 쌓여요(그전 기록은 놀이 수 · 별 · 공부한 날만 있어요).
